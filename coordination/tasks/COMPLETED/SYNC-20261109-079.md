- Übergabegrund: Entscheid des Inhabers (Chat, 2026-11-09): Die in -055 (Frage a, INFO aus Review) offene Lücke soll geschlossen werden, falls nicht umgesetzt. PM-Prüfung: Task-Datei -055 und Code zeigen keine Rückfrage; Stand also nicht umgesetzt.
- Aufgabenbeschreibung: Unter SETUP meldet sich der Profil-Editor bei GUID an einem Host ohne bekannte Kennung ohne Rückfrage an (Einrichtungsausnahme -058, Residualrisiko R1). Das gilt auch, wenn der Benutzer im Editor eines **bestehenden** Profils den Host auf einen anderen, unbekannten PC ändert. Neu: Wird im Editor eines bereits gespeicherten Profils der Host geändert und ist der neue Host (bzw. dessen PC-Kennung) nicht bekannt, erscheint **vor dem Senden von Zugangsdaten** eine Rückfrage (Host alt → neu, Hinweis, dass Zugangsdaten an diesen PC gesendet werden; Bestätigen/Abbrechen). Bei der **Ersteinrichtung** eines neuen Profils bleibt es ohne Rückfrage (unverändert). Ohne Bestätigung keine Anmeldung, keine Speicherung des neuen Hosts mit Lernen der Kennung.
- Technischer Kontext: Bestehende Rückfrage «Anderer PC unter demselben Server» (nur «Verbindung testen», `ui/ProfileScreen.kt` um Z. 325) betrifft bekannten Host mit abweichender Kennung und bleibt unverändert; ggf. Dialog/Texte wiederverwenden statt parallele Implementierung.
