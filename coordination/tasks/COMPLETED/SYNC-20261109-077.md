Bewusst so belassen. Verworfen: Umbenennung in «Abbrechen», Verhaltensänderung zu echter Pause. Begründung Inhaber: «Pause» passt vom Kontext besser.
  3. **Rückfrage beim Hostwechsel (Einrichtungsausnahme präzisiert):** Beim Ersteinrichten eines Profils bleibt die Anmeldung bei unbekanntem PC ohne Rückfrage (Ausnahme -058). Ändert der Benutzer im Editor eines **bestehenden** Profils den Host auf einen unbekannten PC, erscheint vor dem Senden der Zugangsdaten eine Rückfrage. Begründung: Zugangsdaten nicht an einen falschen oder fremden Rechner senden (Residualrisiko R1 aus -055/-058 verkleinern). Verworfen: keine Rückfrage (Residualrisiko akzeptieren). Quelle: -079 (Umsetzung, Endstand abwarten); Entscheid Inhaber 2026-11-09.
