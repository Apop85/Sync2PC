- Aufgabenbeschreibung:
  1. **Restzeit (nachgewiesen, Screenshot):** Zu Beginn eines Laufs (0 B übertragen, 47 Dateien, 340 MB) zeigt die Startseite «noch ca. 411967 Std. 51 Min.». Restzeit erst anzeigen, wenn eine belastbare Übertragungsrate vorliegt (Mindestmenge/-dauer), und oberhalb einer sinnvollen Grenze ausblenden oder «wird berechnet» anzeigen (Text in beide Sprachdateien). Fundort: Fortschrittsberechnung/Anzeige auf der Startseite (Development ermittelt die Stelle; nicht von QA gelesen).
  2. **Lint (`gradlew lintDebug` schlägt fehl, 8 Fehler, 162 Warnungen; `assembleRelease` läuft durch, da nur `lintVital`):** (a) `NewApi` `sync/SyncWorker.kt:69` und `:87`: `getStopReason()`/`WorkInfo.STOP_REASON_*` benötigen API 31, minSdk ist 29. Prüfen, was dort auf API 29/30 zurückgegeben wird; wichtig: wird ein Abbruch durch den Benutzer unter API < 31 fälschlich als Unterbruch (`markInterrupted`) gewertet, was ein ungewolltes Fortsetzen auslöst? Auf dem API-29-Emulator kein Absturz beobachtet, Verhalten ungeprüft. Gegebenenfalls mit `Build.VERSION.SDK_INT >= 31` absichern. (b) `SuspiciousIndentation` `ui/ProfileCards.kt:103` und `:165` (vermutlich harmlos, Einrückung der `SectionCard`-Aufrufe prüfen). (c) `StringFormatInvalid` `values-de/strings_profile.xml:93` (`profile_guard_percent`, «% g…» sieht wie eine Formatangabe aus; wird über `str(id)` ohne Argumente gelesen, daher aktuell harmlos, aber fragil: «%%» schreiben oder Text umformulieren, beide Sprachen). (d) `MissingTranslation` `app_name`: gewollt, mit `translatable="false"` kennzeichnen. Restliche 162 Warnungen nicht Teil dieses Auftrags.
