# SYNC-20261112-269 – Auftrag-guard: Alias-Sperre löst bei reinem Text aus (Fehlalarm)
- Erstellt am: 2026-11-12
- Absender: QA & Testing
- Empfänger: Development
- Priorität: LOW
- Status: COMPLETED
- Aufgabenbeschreibung: tools\Auftrag-guard.ps1 prüft Alias-Funktionsnamen per Regex auf dem ganzen Befehlstext. Fehlalarme (Exit 2): (a) PowerShell-Befehl, der «function rd» nur als Suchmuster oder in einem Text enthält; (b) Aufruf von tools\Auftrag.ps1 mit -Aufgabe/-Kontext/-Wert, in denen «function rd {…}» steht (z. B. Fehlerbericht zur Alias-Falle), weil die Alias-Prüfung vor der Ausnahme für Auftrag.ps1 läuft. Gewünscht: Aufrufe von Auftrag.ps1 von der Alias-Prüfung ausnehmen (oder nur echte Funktionsdefinitionen am Statement-Anfang prüfen, nicht Text in Anführungszeichen), echte Fälle (function rd { … } als Code, auch .ps1-Dateien) bleiben Exit 2. Selbsttest um beide Fehlalarmfälle ergänzen.
  Reproduktion: Hook mit {"tool_name":"PowerShell","tool_input":{"command":"powershell -File tools\\Auftrag.ps1 erstellen ... -Aufgabe 'Beispiel: function rd { }' ..."}} auf stdin ergibt Exit 2. Gewünscht Exit 0.
- Technischer Kontext: Befund B1 aus SYNC-20261112-261 (Prüfbericht dort). Zwischenlösung für Nutzer: Text über -Eingabe <Datei>. Fehlalarm tritt nur bei Text auf, die Sperre selbst wirkt (36 Hook-Proben, übrige wie erwartet).
- Abhängigkeiten: SYNC-20261112-261
- Erwartetes Ergebnis: Hook lässt beide Fehlalarmfälle durch und blockiert weiterhin echte Alias-Funktionen; Selbsttest grün.
- Durchgeführte Arbeiten: tools/Auftrag-guard.ps1: Alias-Prüfung ignoriert Text in Anführungszeichen (auch Here-Strings) bei Aufrufen von Auftrag.ps1 und bei reinen Lesebefehlen; bei -Command, iex, Skriptblock aus Text, -EncodedCommand oder schreibenden Befehlen gilt weiter der ganze Befehlstext. Selbsttest um 4 Fehlalarm- und 5 Sperrfälle ergänzt.
- Tests und Ergebnisse: tools\Auftrag-guard-Selbsttest.ps1: 49 OK, 0 Fehler.
- Verbleibende Risiken: Heuristik: Alias-Funktion in Text, der anders als erkannt ausgeführt wird, wird nicht erkannt (Grenze des Wächters: hält Versehen auf).
